# SecureAuth With AES-256

Manual Implementation of Bcrypt Algorithm With AES-256 And Uses in W3 Application.
Cyber Sicurity Project

## 🚀 Features

- **Core Feature A:** Sign Up With Name Email And Password.
- **Core Feature B:** Password Will Be encrypted And Store in Postgress Database(Neondb).
- **Performance:** Login With Your Email Password.The Password will decrypt and Match Finally Redirect to Dashboard.

## 📦 Tech Stack

- **Backend:** Node.js, Express
- **Frontend:** ReactJs
- **Database:** PostgreSQL([Neondb](https://neon.com/))

## 🛠️ Getting Started

Follow these steps to set up the project locally.

### Prerequisites

List the software needed to run the project:
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ohidurgclan/CyberSicurity.git
   ```

2. Navigate to the project directory:
   ```bash
   mkdir project-name
   cd project-name
   ```

3. Install dependencies: For Backend
   ```bash
   cd backend
   npm install
   ```

4. Set up your environment variables by copying the example file:
   ```bash
   Make a .env file and add these Field

   DATABASE_URL= [Your Neon Connection String]
   PASSWORD_SECRET_KEY=[]
   PASSWORD_SALT_ROUND=[A Integer Number]
   PORT=[Your Example Port]
   ```
5. Install dependencies: For Frontend
   ```bash
   cd Frontend
   npm install
   ```
### Run the Application

Start the local development server: Open Two Tarminal Saperately Frontend & Backend
```bash
cd frontend
cd backend
npm run dev
```
